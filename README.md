# React E-Commerce

A sleek, ultra-minimalist e-commerce storefront for premium tech and lifestyle gear, built with React and Redux Toolkit.

## Overview

**SG Commerce** is a modern, high-end e-commerce web application designed for premium tech gadgets, wearables, and lifestyle accessories. Built with React and Redux Toolkit, the storefront features an ultra-minimalist, pure black aesthetic with sleek glassmorphism UI elements. It includes seamless global state management for the shopping cart, dynamic category filtering, responsive grid layouts, and buttery-smooth micro-animations.

## Key Features

- **Ultra-Minimalist UI:** Pure black aesthetic with glassmorphism overlays and smooth CSS animations.
- **Global State Management:** Seamless add-to-cart and quantity management powered by Redux Toolkit.
- **Dynamic Filtering:** Instant product category filtering via URL search params.
- **Fully Responsive:** CSS Grid and Flexbox layouts optimized for mobile, tablet, and desktop viewing.

## Tech Stack

- **Framework:** React + Vite
- **State Management:** Redux Toolkit
- **Routing:** React Router DOM
- **Icons:** Lucide React
- **Styling:** Vanilla CSS (CSS Variables, Flexbox, Grid)

## Getting Started

To run this project locally:

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. Open your browser and visit `http://localhost:5173`
